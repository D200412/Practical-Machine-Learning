# 2.4 Feature(特征) Engineering(工程)

- Machine learning algorithms prefer well defined fixed(固定的) length input / output
- Feature engineering (FE) is the key to ML models before deep learning (DL)
  - In a computer vision task, people try various FE methods and then train a SVM model
-  DL train deep neural networks to extract(提取) features
  - Features are relevant(相关的) to the task.

![image-20260822231409507](http://look-this-world.oss-cn-qingdao.aliyuncs.com/HelloWorld/image-20260822231409507.png)

## Tabular(表格) Data Fearures

-  Int/float: directly(直接) use or or bin to n unique(唯一) int values
- Categorical(分类) data: one-hot(独热) encoding
  - Map rare categories(分类) into "Unknown"
    <font color="blue">注：将不常见的数据或者噪声当做不知道的，聚焦在重要的信息上</font>
- Date-time: a feature list such as
  -  [year, month, day, day_of_year, week_of_year, day_of_week]

- Feature combination(组合): Cartesian(笛卡尔积) product of two feature groups
  - [cat, dog] x [male, female]  -> [(cat, male), (cat, female), (dog, male), (dog, female)]

## Text Features

- Represent(表示) text as token features
  - Bag of words (BoW) model
    - Limitations(局限性): needs careful vocabulary(词汇) design(设计), missing context(语境)
      <font color="blue">注：句子词元之间会有时序，因此会丢失语境</font>
  - Word Embeddings(嵌入) (e.g. Word2vec):
    - Vectorizing(向量化) words such that similar words are placed close together
    - Trained by predicting target(目标) word from context words
- Pre-trained language models (e.g. BERT, GPT-3)
  ![image-20260823001838478](http://look-this-world.oss-cn-qingdao.aliyuncs.com/HelloWorld/image-20260823001838478.png)
  - Giant(巨型) transformer models
  - Trained with large amount of unannotated(没标注的) data
    <font color="blue">通过自训练的自监督学习，能够比较好的抽取时序的信息</font>
  - Fine-tuning for downstream(下游的) tasks

## Image/Video Features

- Traditionally extract images by hand-craft(手动提取) features such as SIFT
- Now commonly use pre-trained deep neural networks
  - ResNet: trained with ImageNet (image classification)
  -  I3D: trained with Kinetics (action classification)
