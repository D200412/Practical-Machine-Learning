# 5.3 Boosting

- Boosting combines(结合) weak learners into a strong one
  -  Primarily(主要) to reduce bias
- Learn $n$ weak learners **sequentially(依次的)**, at step $i$:
  - Train a weak learner $h_i$, evaluate(评估) its errors $\epsilon_t$
  - Re-sample data accordin to $\epsilon_t$, to focus on wrongly predicted examples
- Notable examples incluede AdaBoost, gradient boosting

## Gradient Boosting

- Denote(表示) by $H_i(x)$ the model at time $t$, with $H_1(x) = 0$
- At step $t=1,……$
  - Train a new model $h_t$, on residuals(残差): $\{(x_i,y_i- H_i(x_i))\}_{i=1,…,m}$
  - $H_{t+1}(x)=H_t(x)+\eta h_t(x)$
    - The learning rate $\eta$ regularizes(正则项) the model by shrinkage(收缩)
- The residuals equal to $-\frac{\partial L}{\partial H} $ if using MSE as the loss
- Other boosting algorithms (e.g. AdaBoost) can also be gradient descent in the function space

## Gradient Boosting Decision Trees (GBDT)

- Use decision tree as the weak learner
  - Regularize by a small max_depth and randomly sampling features
- Sequentially constructing trees runs slow
  - Popular libraries use accelerated(加速的) algorithm,e.g. XGBoost, lightGBM
