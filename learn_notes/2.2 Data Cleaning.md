# 2.2 Data Cleaning

## Data Errors

- Data often have errors - the mismatch(不匹配) with ground truth(真实值)
  - e.g. missing, erroneous or extreme(极端) values
- Good ML models are resilient(弹性的) to errors
  - The training often converges(收敛), but the accuracy(精确度) is degraded
- Deploying(部署) these models online may impactthe quality of the new collected data

## Types of Data Errors

- <font color="ca6924">Outliers(异常值):</font> data values that deviate(背离) from the distribution(分布) of values in the column
- <font color="ca6924">Rule violations(违反):</font>> violate integrity(完整性) constraints(约束) such as "Not Null"and "Must be unique”
- <font color="ca6924">Pattern(模式) violations:</font> violate syntactic(语法) and semantic(语义) constraints such as alignment(对齐), formatting, misspelling(拼写错误)

##  Rule-based Detection

- <font color="ca6924">Functional(功能性) dependencies:</font>> $x → y$ means a value $x$ determines(决定) a unique(唯一的) value $y$
  - E.g. zip code → state, EIN → company name
- <font color="ca6924">Denial(否定) constraints(约束):</font> a more flexible(灵活的) first-order logic formalism(形式)
  - Phone number is not empty if vendor(供应商) has an EIN
  -  If two captures(捕捉) of the same animal indicated(指向) by the same tag number, then the first one must be marked as original
