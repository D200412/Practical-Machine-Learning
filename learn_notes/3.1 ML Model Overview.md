# 3.1 ML Model Overview

## Types of ML Algorithm

### <font color="ca6924">Supervised(监督)</font>

Train on labeled data to predict labels

-  Self-supervised: labels are generated from data (E.g.word2vec, BERT)

### <font color="ca6924">Sumi-supervised(半监督)</font>

Train on both labeled and unlabeled data, learn models to predict labels or infer labels for unlabeled data

- E.g. self-training

### <font color="ca6924">Unsupervised(无监督)</font>

Train on unlabeled data

- E.g. clustering(聚类), density estimation(估计)(GAN)

### <font color="ca6924">Reinforcement(强化)</font>

<font color="blue">注：从环境中获得一些观察点之后再进行学习</font>

Use observations(观察结果) from the interaction(交互) with the environment to take actions to maximize reward

## Components(组件) in Supervised Training

### <font color="ca6924">Model</font>

Output predicts from inputs

- E.g. listing house - sale price

### <font color="ca6924">Loss</font>

Measure(测量) difference between predicts and ground truth labels

- E.g. $(\text{predict price - sale_price})^2$

### <font color="ca6924">Objective(目标函数)</font>

Any function to optimize(优化) during training

- E.g. minimize the sum of losses over examples

### <font color="ca6924">Optimization(优化)</font>

Learn model parameters(参数) by solving the objective function

## Types of Supervised Models

### <font color="ca6924">Decision trees</font>

Use trees to make decisions

### <font color="ca6924">Linear methods</font>

Decision is made from a linear combination(组合) of inputs

### <font color="ca6924">Kernel(内核) machines</font>

Use kernel functions to compute feature similarities(相似度)

### <font color="ca6924">Neural Networks</font>

Learn model parameters(参数) by solving the objective function
