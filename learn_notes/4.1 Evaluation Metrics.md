# 4.1 Evaluation Metrics(评估指标)

## Model Metrics

- In supervised(监督) learning, we train models by minimizing the training loss
  - The loss value is a widely used metric to measure(测量) model quality
- There are many other metrics
  -  Model specific: e.g. accuracy(准确性) for classification, mAP for object detection(检测)
    <font color="blue">mAP: Mean Average Precision 平均精度均值</font>
  - Business specific: e.g. revenue(收入), inference(推理) latency(延迟)
- We select models by multiple metrics
  - Just like how you choose cars

## Metrics for Classification

- Accuracy:  correct predictions /  examples

  ```python
  sum(y == y_hat) / y.size
  ```

- Precision(精度):  correctly predicted as class $i$  /  predicted as class $i$

  ```python
  sum((y_hat == 1) & (y == 1)) / sum(y_hat == 1)
  ```

- Recall: # correctly predicted as class i/ # examples

  ```python
  sum ((y_hat == 1) & (y == 1)) / sum (y == 1)
  ```

- F1: Balance precision and recall

  - the harmonic(调和) mean of precision and recall: $2pr/(p + r)$

## AUC & RUC

- AUC, the area under ROC curve(曲线), measures the chance a model can distinguish(区分) classes

## Business Metrics for Displaying Ads(广告)

- Optimize(优化) both revenue and customer experience(体验)
  - Latency(延迟): ads should be shown to users at the same time as others
    <font color="green">300ms~500ms以内</font>
  - ASN: average #ads shown in a page
    <font color="green">一个页面中投放广告的平均数量</font>
  - CTR: user click through rate
    <font color="green">真实用户点击的概率(不是模型预测的)</font>
  - ACP: average price advertiser(广告商) pays per click
- revenue = pageviews(流量) x ASN x CTR x ACP

## Displaying Ads: Model - Business Metrics

- The key model metric is AUC
- A new model with increased AUC may harm business metrics
  - It selects different ads to display, these ads may have
    - Lower estimated(估计的) CTR → less ads displayed
    - Lower real CTR because we only evaluated(已评估) on past data
    - Lower prices
- The solution is to deploy models to evaluate on real traffic(流量) data
