## Semi-Supervised(半监督) Learning (SSL)

- Focus on the scenario(场景) where there is a small amount of labeled data, along with large amount of unlabeled data
- Make assumptions(假设) on data distribution(分布) to use unlabeled data
  - <font color="ca6924">Continuity(连续性) assumption:</font> examples with similar features(特征) are more likely to have the same label
  - <font color="ca6924">Cluster(聚类) assumption:</font> data have inherent(具有) cluster structure, examples in the same cluster tend to have the same label
  - <font color="ca6924">Manifold(流形) assumption:</font> data lie on a manifold of much lower dimension(维度) than the input space

## Self-training(自训练模型)

- Self-training is a SSL method

![image-20260818233143562](http://look-this-world.oss-cn-qingdao.aliyuncs.com/HelloWorld/image-20260818233143562.png)

- We can use expensive models
  - Deep neural network, model ensemble(融合)/bagging

## Active(主动) Learning

-  Focus on same scenario(场景) as SSL but with human intervention
  - Select the most "interesting" unlabeled data to labelers
- <font color="ca6924">Uncertainty(不确定性) sampling(采样)</font> chooses an example whose prediction(预测) is most uncertain(不明确)
  - The highest class(类别) prediction score is close to random **(1/n)** 
    <font color="blue">注：该样本属于哪一个类的概率都差不多，无法分辨</font>
- Similar to self-training we can use expensive models
  - <font color="ca6924">Query-by-committee</font> trains multiple models and select samples that models disagree with

## Active Learning + Self-training

- These two methods are often used together

## Quality Control

- Labelers make mistakes (honest or not) and may fail to understand the instructions(指令)
- Simplest but most expensive: sending the same task to multiple labelers, then determine(取决) the label by majority(大部分) voting(投票)
  - Improve: repeat more for controversial(有争议的) examples, prune(剔除) low-quality labelers

## Weak Supervision(弱监督)

- Semi-automatically(半自动地) generate(生成) labels
  - Less accurate(精度) than manual(手动的) ones, but good enough for training
- <font color="ca6924">Data programming(编程):</font> heuristic(启发式的) programs to assign(分配) labels
  - Keyword search, pattern(模式) matching(匹配), third-party models
