## Random Forest(随机森林)

-  Train multiple decision trees to improve robustness 
  - Each tree is trained independently(独立的)
  - Majority voting(投票) for classification, average for regression
- Where is the randomness from?
  - Bagging: randomly sample(采样) training examples with replacemen(替换)
     E.g. [1,2,3,4,5] → [1,2,2,3,4]
  - Randomly select a subset(子集) of features

## Gradient Boosting(提升) Decision Trees

- Train multiple trees sequentially(顺序的)
- At step $t = 1,...$, denote(表示) by $F_t(x)$ the sum of past trained trees
  - Train a new tree $f_t$ on residuals(残差): $\{(x_i, y_i - F_t(x_i))\}_{i=1},...$
  - $F_{t+1}(x)=F_t(x)+f_(x)$
- The residual(残差) equals to $-\partial{L}/\partial{F}$  if using mean square as the loss, so it's called gradient boosting
