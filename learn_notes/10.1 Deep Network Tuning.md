## Batch and Layer Normalization

- Standardizing data makes the loss smother(平滑) for linear methods
  - Smooth: $\| \nabla f(\mathbf{x}) - \nabla f(\mathbf{y}) \|^2 \leq \beta \|\mathbf{x} - \mathbf{y}\|^2$
  - A smaller $\beta$ allows a larger learning rate
  - Does not help deep NN
- Batch Normalization (BN) standards inputs for internal(内部的) layers
  - Improves the smoothness to make training easier
  - (Still controversial(有争议的) why BN works)

## Batch Normalization

- <font color="ca6924">Reshape</font> input $\mathbf{X}$ into 2D (no change for 2D input $\mathbf{X} \in \mathbb{R}^{n×r}$
  - $\mathbf{X} \in \mathbb{R}^{n×c×w×h} → \mathbf{X}'\in \mathbb{R}^{nwh×c}$ (batch $n$, channel $c$, width $w$, height $h$)
- <font color="ca6924">Normalize</font> by standardization each column $x'_j, j = 1,....$
  - $\hat{x}'_j\gets(x'_j-mean(x'_j))/std(x'_j)$
- <font color="ca6924">Recovery(恢复)</font> $\mathbf{Y}'$ with $y'_j = \gamma_j\hat{\mathbf{x}}_j +\beta_j$ as the $j$-th column, $\gamma_j$, $\beta_j$ are parameters
- Output $\mathbf{Y}$ by reshaping $\mathbf{Y}'$ to the same shape as $\mathbf{X}$

## Batch Normalization Code

```python
# moving_mean, moving_var是用来做预测的
def batch_norm(X, gamma, beta, moving_mean, moving_var, eps, momentum):
	if not torch.1s_grad_enabled(): # In prediction mode
		X_hat = (X - moving_mean) / torch.sqrt(moving_var + eps)
	else:
		assert len(X.shape) in (2, 4)
    	if len(X.shape) == 2:
            mean = X.mean(dim=0)
			var = ((X - mean)**2).mean(dim=0)
		else:
			mean = X.mean(dim=(0, 2, 3), keepdim=True)
            var = ((X - mean)**2).mean(dim=(0, 2, 3), keepdim=True)
        X_hat = (X - mean)/ torch.sqrt(var + eps)
        moving_mean = momentum * moving_mean + (1.0 - momentum)
        moving_var = momentum * moving_var + (1.0 - momentum)
	Y = gamma * X_hat + beta
	return Y, moving_mean, moving_var
```

## Layer Normalization

- If apply to RNN, BN needs maintain(维护) separated(独立的) moving statistics for each time step
  - Problematic(有问题的) for very long sequences during inference(推断)
- Layer normalization reshapes input $\mathbf{X} \in \mathbb{R}^{n×P} → \mathbf{X}' \in \mathbb{R}^{p×n}$ $\mathbf{X} \in \mathbb{R}^{n×c×w×h} → \mathbf{X}' \in \mathbb{R}^{cwh×n}$, rest is Same with BN
  - Normalizing within each example, up to current(当前) time step 
  - Consistent(一致的) between training and inference
  - Popularized by Transformers

## More Normalizations

- Modify(修改) "reshape",e.g.
  - InstanceNorm: $n×c×w×h → wh×cn$
  - GroupNorm:$n×c×w×h → swh×gn$ with $c = sg$
  - CrossNorm: swap mean/std betweena pair of features
- Modify "normalize":e.g. whitening(<font color="blue">使得每一个特征之间使没有关系的</font>)
- Modify"recovery": e.g. replace $\gamma, \beta$ with a dense layer
- Apply to weights or gradients(梯度)
