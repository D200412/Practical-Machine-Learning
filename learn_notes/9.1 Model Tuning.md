# 9.1 Model Tuning(调参)

## Manual Hyperparameter Tuning

- Start with a good baseline, e.g. default settings in high-quality toolkits(工具包), values reported in papers
-  Tune a value, retrain the model to see the changes

- Repeat multiple times to gain(获得) insights(洞察) about
  - Which hyperparameters are important
  - How sensitive the model to hyperparameters
  - What are the good ranges
- Needs careful experiment management
- Save your training logs and hyperparameters to compare, share and reproduce(复制) later
  - The simplest way is saving logs in text and put key metrics(指标) in Excel
  - Better options exist(存在), e.g. tenesorboard and weights & bias
- Reproducing is hard, it relates to 
  - Environment (hardware & library)
  - Code
  - Randomness (seed)

## Automated Hyperparameter Tuning

- Computation costs decrease exponentially(指数级的), while human costs increase
- Cost per training for a typical(典型的) ML task:
  - E.g. 1M user logs, 10K images
- Cost of a data scientist per day >$500
- Use algorithms if it outperforms human after 1000trials
- Typically beat 90% data scientists

## Automated Machine Learning (AutoML)

- Automate every step in applying ML to solve real-world problems: data cleaning,feature extraction(提取), model selection...
- Hyperparameter optimization(优化) (HPO):find a good set of hyperparameters through search algorithms
- Neural architecture search (NAS):construct(构建) a good neural network model
