# 4.3 Model Validation(验证)

## Estimate Generalization Error

- Approximated(近似值) by the error on a <font color="ca6924">test dataset</font>, which can be only used once
  - Your score on midterm(期中) exam
  - The house sale price I bided(出价)
  - Dataset used in private leaderboard in Kaggle
- <font color="ca6924">Validation(验证) dataset</font>: can be used multiple times
  - Often a part of the training dataset
  - When we use "test", in most time we mean "validation"

## Hold Out Validation

- Split your data into "train" and "valid" sets (often calls "test")
  - Train your model on the train set, use the error on the valid set to approximate the
    generalization error
- Often randomly select $n \%$ examples as the valid set
  -  Typical(典型) choices $n = 50, 40, 30, 20, 10$

## Split non I.I.D. data

- Random splitting may not work
  <font color="blue">随机行：假设我整个数据每个样本之间是符合一个独立同分布的时候</font>
- Sequential(时序的) data: e.g. house sales, stock prices
  - Valid set should after train set
- Examples belongs to gro ps: e.c phott :; of the same person
  - Split among groups instead of examples
- In-balanced data
  - Sample more from minor classes

## K-fold Cross Validation(K折交叉验证)

- Useful when not sufficient(足够的) data
- Algorithm:
  - Partition(区分) the training data into K parts

  - For $i= 1, ..., K$
    - Use the $i$-th part as the validation set, the rest for training
  - Report the averaged the K validation errors
- Popular choices: K = 5 or 10

<font color="blue">当数据比较少的时候，取比较大的K，但是要重复更多的次数；当数据比较多，取比较少的K</font>

## Common Mistakes

- Personal opinion: 90% super good results in ML are due to bugs
  - Contaminated(受污染的) valid set is the #1 reason
- Valid set has examples from train set
  <font color="blue">验证集和训练集有一定的重叠</font>
  -  Duplicated(重复的) examples in original data
  - Often happen when integrating(融合) data
    - Scrape images from search engine(引擎) to evaluate(评估) models trained on ImageNet
- Information leaking(泄露)
  - Often happen for non I.l.D data: 
    e.g. use future to predict past, see a person's face before
