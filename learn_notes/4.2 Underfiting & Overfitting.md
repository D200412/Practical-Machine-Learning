# 4.2 Underfiting(欠拟合) & Overfitting(过拟合)

## Training and Generalization(泛化) Errors

- <font color="ca6924">Training error</font>: model error on the training data
- <font color="ca6924">Generalization error</font>: model error on new data
- Example: practice a future exam with past exams
  - Doing well on past exams (training error) doesn't guarantee(保证) a good score
    on the future exam (generalization error)
  - Student A gets 0 error on past exams by rote learning
  - Student B understands the reasons for given answers

## Model Complexity

- The ability(能力) to fit variety of functions
  - Low complexity models struggles to fit training set
  - High complexity models can memorize the training set
- It's hard to compare between ven/ different algorithms
  - E.g. trees vs neural network
- In an algorithm family, two factors matter:
  - The number of parameters 
  - The values taken by each parameter
    <font color="blue">有值限制的模型会比较简单一点：正则化</font>

## Data Complexity

- Multiple factors matters
  - number of examples

  - number of elements in each example
  - time/space structure
    <font color="blue">股票数据是有时间结构的，图片数据是由有空间结构的</font>
  - diversity(多样性)
    <font color="blue">样本是否多样，有很多种类</font>
- Again, hard to compare among very different data
  - E.ga char vs apixel

## Model Selection

- Pick a model with a proper(适当的) complexity for your data
  - Minimize the generalization error
  - Also consider business metrics
- Start with pick up a model family, then select proper hyper-parameters

- Trees: #trees, maximal depths
- Neural networks: architecture(架构), depth (#layers), width (#hidden units(单元)),regularizations(正则化)
