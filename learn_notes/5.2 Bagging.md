## Bagging - <font color="ca6924">B</font>ootstrap <font color="ca6924">AGG</font>rgrat<font color="ca6924">ING</font>

- Bagging trains $n$ base learners in parallell(平行)
- Make decisions by averaging learners' outputs (regression) or majority(多数) voting(投票) (classification)
- Each learner is trained on data by bootstrap sampling(采样)
  - Assume(假设) $m$ training examples, then randomly sampling $m$ examples with replacement(替换)
  - Around $1 - 1/e ≈ 63 \%$ examples will be sampled, the rest (out of-bag) can be used for validation

```python
class Bagging:
    def __init__(self, base_learner, n_learners):
        self.learners = [clone(base_learner) for _ in range(n_leatners)]
        
    def fit(self, X, y):
        for learner in self.learners:
            examples = np.random.choice(
            	np.arange(len(X), int(len(X)), replace=True)
            learner.fit(X.iloc[examples, :], y.iloc[examples])
     
     def predict(self, X):
     	preds = [learner.predict(X) for learner in self.learner]
        return np.array(preds).mean(axis=0)
```

## Unstable(不稳定) Learners

- Bagging reduces variance, especially for unstable learners

- Consider regression for simplicity(简单性), given ground truth $f$ and base learner $h$, bagging: $\hat{f}(x) = E[h(x)]$

- Given $E[x]^2≤E[x^2]$, we have
  $$
  \left(f(x)-\hat{f}(x)\right)^2
  \leq
  E\left[\left(f(x)-h(x)\right)^2\right]
  \Longleftrightarrow
  \left(E[h(x)]\right)^2
  \leq
  \mathbb{E}\left[h(x)^2\right]
  $$

- Bagging reduces more variance when base learners are unstable

- Decision tree is unstable, linear regression is stable
