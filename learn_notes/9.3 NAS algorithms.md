# 9.3 NAS algorithms

## Neural Architecture(架构) Search (NAS)

- A neural network has different types of hyperparameters:
  - Topological(拓扑的) structure: resnet-ish, mobilenet-ish, #layers
  - Individual layers: kernel_size(卷积核尺寸), #channels in convolutional layer, #hidden_outputs in dense/recurrent(循环) layers
- NAS automates the design of neural network
  - How to specify(指定) the search space of NN
  -  How to explore the search space
  - Performance estimation(估算)

## NAS with Reinfocement(强化) Learning

- [Zoph & Le2017](https://arxiv.org/abs/1611.01578)
  - A RL-based controller (REINFORCE) for proposing architecture.
  - RNN controller outputs a sequence(序列) of tokens to config the model architecture.
  - Reward is the accuracy(准确性) of a sampled model at convergence(收敛)
- Naive(朴素) approach(方法) is expensive and sample in-efficient (~2000 GPU days). To speed up NAS:
  - Estimate performance
  - Parameter sharing (e.g. EAS, ENAS)

## The One-shot Approach

- Combines(结合) the learning of architecture and model params
- Construct and train a single model presents a wide variety(多样性) of architectures
- Evaluate candidate(候选者) architectures
  - Only care about the candidate ranking
  - Use a proxy(近似) metric: the accuracy after a few epochs
- Re-train the most promising candidate from scratch

## Differentiable(可微的) Architecture Search

- Relax the categorical(分类的) choice to a softmax over possible operations:

  - Multiple candidates for each layer

  - Output of $i$-th candidate at layer $l$ is $o^l_i$;

  - Learn mixing weights $\mathbf{a}^l$. The input for $i + 1$-the layer is
    $$
    \sum_i \alpha_i^l o_i^l
    \quad \text{with} \quad
    \boldsymbol{\alpha}^l = \operatorname{softmax}(\mathbf{a}^l)
    $$

  - Choose candidate $\arg\max_ia_i$;

  - Jointly learn $a^l$ and network parameters

- A more sophisticated(精致的) version (DARTS) achieves SOTA and reduces the search time to ~3 GPU days

## Scaling(调节) CNNs

- A CNN can be scaled by 3 ways:
  - Deeper: more layers
  - Wider: more output channels
  - Larger inputs: increase input image resolutions(分辨率)
- EfficientNet proposes a compound scaling
  - Scale depth by $\alpha^{\phi}$, width by $\beta^{\phi}$, resolution by $\gamma^{\phi}$
- $\alpha\beta^2\gamma^2 ≈ 2$ so increase FLOP(计算复杂度) by 2x if $\phi = 1$
- Tune $\alpha,\beta,\gamma,\phi $

## Research directions(方向)

- Explainability(可解释性) of NAS result
- Search architecture to fit into edge devices
  - Edge devices are more and more powerful, data privacy concerns(问题)
  - But they are very diverse (CUP/GPU/DSP, 100x performance difference) and have power constraints(约束条件)
  - Minimize both model loss and hardware latency(延迟)
    - E.g. minimize loss × $\mathbf{log}(latency)^{\beta}$
- To what extend can we automates the entire ML workflow?
