## Linear Methods → Mulitilayer Perceptron (MLP)

- A <font color="ca6924">dense(稠密层)</font> (fully connected, or linear) layer has parameters $\mathbf{W} \in \mathbb{R}^{m×n}, \mathbf{b}\in\mathbb{R}^m$, it computes output $\mathbf{y} = \mathbf{Wx} + \mathbf{b}\in\mathbb{R}^m$
  <font color="blue">$n$ 为输入特征的维度，$m$ 是输出向量的长度</font>
  - Linear regression: dense layer with 1 output
  - Softmax regression:
    dense layer with $m$ outputs + softmax

## MLP

- Activation(激活函数) is a elemental-wise(按元素分类) non-linear function
  - $\text{sigmoid}(x) = \frac{1}{1 + \exp(-x)}, \quad \text{ReLU}(x) = \max(x, 0)$
    sigmoid操作的输出是 [0, 1] 之间的数 
- Stack(堆叠) multiple hidden layers
  (dense + activation) to get deeper models
- Hyper-parameters:
  hidden layers<font color="blue">（隐藏层的数量)</font>,  
   outputs of each hidden layer<font color="blue">(隐藏层的输出大小）</font>

## Dense layer → Convolution layer

- Learn ImageNet (300x300 images with 1K classes) by a MLP with a single(单个) hidden layer with 10K outputs
  - It leads to 1 billion learnable parameters, that's too big!
  - Fully connected: an output is a weighted sum over all inputs
- Recognize(识别) objects in images
  - <font color="ca6924">Translation invariance(平移不变性)</font>: similar output no matter where the object is
  - <font color="ca6924">Locality</font>: pixels(像素) are more related to near neighbors
- Build the prior knowledge into the model structure
  - Achieve same model capacity(容量) with less # params

## Convolution layer(卷积层)

- Locality: an output is computed from $k × k$ input windows

- Translation invariant: outputs use the same $k × k$ weights (kernel(内核))
  <font color="blue">权重是共享的，不想要重新训练参数</font>>
- #model params of a conv layer does notdepend on input/output sizes 
- A kernel may learn to identify(识别) a pattern(模式)

## Code

- Convolution with single(单个) input and output channels

  ```python
  # both input `X` and weight `K` are matrices
  h, w = K.shape
  Y = torch.zeros((X.shape[0] - h + 1, X.shape[1] - w  + 1))
  for i in range(Y.shape[0]):
      for j in range(Y.shape[1]):
          Y[i, j] = (X[i:i + h, j:j + w] * K).sum()
  ```

## Pooling Layer(汇聚层或者池化层)

- Convolution is sensitive to location

  - A pixel shift(偏移) in the input results in a pixel shift(偏移) in output

- A pooling layer computes mean/max in $k × k$ windows

  ```python
  # h, w: pooling window height and weight
  # mode: max or avg
  Y = torch.zeros((X.shape[0] - h + 1, X.shape[1] - w + 1))
  for i in range(Y.shape[0]):
      for j in range(Y.shape[1]):
          if mode == "max":
              Y[i, j] = X[i:i+h, j:j+w].max()
          elif mode = "avg"
          	Y[i, j] = X[i:i+h, j:j+w].mean()
  ```

## Convolutional Neural Networks (CNN)

- A neural network uses stack(堆叠) of convolution layers to extract(提取) features
  - Activation is applied after each convolution layer
  - Using pooling to reduce location sensitivity
- Modern CNNs are deep neural network with various hyper-parameters and layer connections (AlexNet, VGG, Inceptions, ResNet, MobileNet)

## RNN and Gated RNN

- Simple RNN:$\mathbf{h}_t=\phi(\mathbf{W}_{hh}\mathbf{h}_{t-1}+\mathbf{W}_{hx}\mathbf{x}_t+\mathbf{b}_h)$
  
  ![image-20260826193942295](http://look-this-world.oss-cn-qingdao.aliyuncs.com/HelloWorld/image-20260826193942295.png)

  <font color="blue">在这个简单的RNN中 $\mathbf{y}_t$ 和 $\mathbf{h}_t$ 是一样的</font>

- Gated RNN (LSTM, GRU): finer control of information flow(流动)

  - Forget input: suppress $\mathbf{x}_t$, when computing $\mathbf{h}_t$
  - Forget past: suppress $\mathbf{h}_{t-1}$ when computing $\mathbf{h}_t$,

## Code

- Implement Simple RNN

  ```python
  W_xh = nn.Parameter(torch.randn(num_inputs, num_hiddens) * 0.01)
  W_hh = nn.Parameter(torch.rand (num_hiddens, num_hiddens) * 0.01)
  b_h = nn.Parameter(torch.zeros(num_hiddens))
  
  H = torch.zeros(num_hiddens)
  outputs = []
  
  for X in inputs: # `inputs` shape : (num_steps, batch_size, num_input)
      H= torch.tanh(X @ W_xh + H @ W_hh + b_h)
      outputs.append(H)
  ```
