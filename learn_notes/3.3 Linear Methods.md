# 3.3 Linear Methods

## Linear Regression(回归)

- A simple house price prediction
  - Assume(假设) 3 features: $x_1$ = #beds, $x_2$ = #baths, $x_3$ = living sqft
  - The predicted price is $y= w_1x_1 + w_2x_2 + w_3x_3 + b$ 
  - Weights $w_1, w_2, w_3$ and bias(残差) $b$ will be learnt from training data
- In general, given data $ \mathbf{x}= [x_1,x_2, ...,x_p]$, linear regression predicts
  $y=w_1x_1+w_2x_2+...+w_px_p=\langle\mathbf{w},\mathbf{x}\rangle+b$
  - Trainable weights $\mathbf{w} = [w_1, w_2, ..., w_p]$ and bias $b$

```python
# weight w has shape (p, 1)
# bias b is a scalar
# data x has shape (p, 1)
y_hat = (x * w).sum() + b
```

## Objective Function

- Collect $n$ training examples $\mathbf{X}= [x_1,x_2...,x_n]^T ∈ \mathbb{R}^{n×p}$ with labels $\mathbf{y}=[y_1,...,y_n]^T ∈ \mathbb{R}_n$

  - E.g. house listings and sold prices

- Objective: minimize the mean square error (MSE)(平均均方误差)

  $$
  \begin{align}
  \mathbf{w}^*, \mathbf{b}^*
  &= \arg\min_{\mathbf{w},b} \ell(\mathbf{X}, \mathbf{y}, \mathbf{w}, b) \\
  &= \arg\min_{\mathbf{w},b} \frac{1}{n} \sum_{i=1}^n \| y_i - \langle x_i, w \rangle - b \|^2
  \end{align}
  $$
  
  <font color="blue">注：$y_i$ 表示的是真实的房价，$\langle\mathbf{x}_i,\mathbf{w}\rangle-b$ 为模型预测值</font>

## Use linear regression for classification

- Regression: continuous output in $\mathbb{R}$
- Multi-class classification:
  - Vector outputs, $i$-th output reflects the confidence(置信) score as belongs to class $i$
  - Learn a liner model for each class $o_i= \langle\mathbf{x}, \mathbf{w}_i\rangle + b_i$
  - One-hot label $y=[y_1,y_2,...,y_m]$ where $y_i=1$ if $i=y$ otherwise 0. 
  - Minimize MSE loss $\frac{1}{m}\|\mathbf{o}-\mathbf{y}\|_2^2$
  - Predict label $\arg\max_i\{o_i\}^m_{i=1}$

## Softmax Regression

- One-hot label $y=[y_1,y_2,...,y_m]$ where $y_i=1$ if $i=y$ otherwise 0. 

- Turns scores into probabilities(概率) (non-negative(非负), sum to 1)

  $$
  \hat{\mathbf{y}} = \text{softmax}(\mathbf{o}) \quad \text{where} \quad \hat{y}_i = \frac{\exp(o_i)}{\sum_{k=1}^m \exp(o_k)}
  $$

  - Still a linear model, decision made as $\arg\max_i\hat{y}_i = \arg\max_io_i$

    ```python
    0_exp = torch.exp(0)
    partition = 0_exp.sum(1, keepdim="True")
    Y = 0_exp / partition
    ```

- Cross-entropy(交叉熵) loss between two distributions(分布) $\mathbf{\hat{y}}$ and $\mathbf{y}$
  <font color="blue">比较两个概率的方法</font>

  $$
  H(y, \hat{y}) = \sum_i -y_i \log(\hat{y}_i) = -\log \hat{y}_y
  $$
  
  - When label class is $i$, assigns(分配) less penalty(惩罚) on $o_j$ as long as $o_j \ll o_i$

## Mini-batch(小批量) Stochastic(随机) gradient descent (SGD) 

- Train by mini-batch SGD (by various other ways as well)
  - $\mathbf{w}$ model param, $b$ batch(批量) size, $\eta_t$ learning rate at time $t$
    <font color="blue">其中 $\mathbf{w}$ 是将偏移量去掉，在输入的特征中加了一列全1的特征</font>
  - Randomly initialize(初始化) $\mathbf{w}_1$ 
  - Repeat $t = 1,2,...$ until converge(收敛)
    -  Randomly samples $I_t \subset \{1,...,n\}$ with $|I_t|= b$
    - Update $\mathbf{w}_{t+1}=\mathbf{w}_t-\eta_t\nabla_{\mathbf{w}_t}\ell(\mathbf{X}_{I_t},\mathbf{y}_{I_t},\mathbf{w}_t)$
- Pros: solve all objectives in this course except for trees
  <font color="red">除了决策树以外的所有的算法模型都可以用它来求解</font>
- Cons: sensitive to hyper-parameters $b$ and $\eta_t$

## Code

```python
# `feature` shape is (n, p), `labels` shape is (n, 1)
# 实现每一次在样本里面采样一个批量大小的小批量出来
def data_iter(batch_size, features, labels):
    num_examples = len(features)
    indics = list(range(num_examples))
    random.shuffle(indics)  # read examples at random
    for i in range(0, num_examples, batch_size):
        # 拿出批量大小的下标
        bach_indices = torch.tensor(
            indics[i:min(i + batch_size, num_examples)]
        )
        yield features[bach_indices], labels[bach_indices]

# 使用了均值为0，方差为0.01的高斯分布来初始化
w = torch.normal(0, 0.01, size=(p, 1), requires_grad=True)
b = torch.zeros(1, requires_grad=True)

for epoch in range(num_epochs):
    for X, y in data_iter(batch_size, features, labels):
        y_hat = X @ w + b
        loss = ((y_hat - y) ** 2).mean()
        loss.backward()
        for param in [w, b]:
            param -= learning_rate * param.grad
            param.grad.zero_()
```
